# ChatApp

A simple Java Swing-based desktop chat application powered by a REST API backend.

## Overview

ChatApp delivers a lightweight messaging client built using Java Swing for the UI layer and a RESTful API for backend communication. The current version focuses on core messaging capabilities with a roadmap for advanced collaboration features.

## Features (Current Version)

- User Registration
- User Authentication (Login)
- Send Messages
- Edit Messages
- Delete Messages
- Personal contact management
- Message read receipts

- REST API-based communication
- Simple and responsive Swing UI

## Upcoming Features

- Emoji support
- File and media attachments
- Online status indicators
- Improved UI/UX enhancements

## Tech Stack

- Java (Swing UI)
- REST API (Backend integration)
- JSON for data exchange
- HTTP Client for API calls

## Architecture

- **Frontend:** Java Swing desktop client
- **Backend:** REST API service
- **Communication:** JSON over HTTP
